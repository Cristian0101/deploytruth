# Changelog

DeployTruth follows a lightweight milestone history while it is pre-1.0. User-facing releases will
adopt semantic versioning when the package is ready for publication.

## Unreleased

## 0.1.0

- M1 local Git truth.
- M2 GitHub authoritative source truth.
- M3 Vercel production deployment truth.
- M4 Supabase project, database identity, and migration truth.
- M5 runtime connection truth.
- M6 loopback-only visual Truth Map, evidence Inspector, and local report UX.
- M7 local report history and semantic run comparison (`history`, `diff`, History UI).
- M8 distributable GitHub Action — Job Summary, machine outputs, sanitized evidence bundle, and a
  `fail-on` policy over the same truth engine.
- The CLI packaged for external install as the `deploytruth` npm package (`npm install -g
deploytruth` / `npx deploytruth`), a self-contained bundle with zero runtime dependencies.
- Established the public open-source repository and controlled live acceptance environment.
